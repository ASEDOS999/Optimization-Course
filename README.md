# Теория и методы оптимизации

## Осенний Семестр

[Полная программа и правила курса](program.pdf)

Все величины ниже измеряются в шкале от 0 до 10.

| Символ | Тип работы | Пояснение |
|---|---|---|
| **H** | Домашние задания | 4 общих домашних задания за семестр, примерно по одному на каждые 4 недели. Сдача через Google-форму. Мягкий дедлайн: в течение недели после дедлайна каждый день опоздания снимает 1/7 балла за работу, по истечении недели работа не принимается. Итоговый балл — среднее по четырём работам |
| **C** | Работа на семинарах | Оценка семинариста за устные сдачи домашних заданий, короткие тесты на семинарах, зачёты или другие процедуры. Правило выставления этой оценки остаётся на усмотрение семинариста |
| **M** | Контрольная работа | Общая потоковая контрольная работа после 8-й недели, в субботу или воскресенье, продолжительностью примерно 3 часа |
| **A** | Аудиторный балл | `A = 0.5·M + 0.5·C` |
| **S** | Оценка за семестр | `S = Round(min(0.5·H + 0.5·A, A + 2))` |
| **E** | Экзамен | Проводится в конце семестра |
| **F** | Итоговая оценка | `F = E`, если `E ≤ 2`; иначе `F = Floor(min(10, 0.5·S + 0.6·E))`. Эта оценка влияет на финальную оценку во втором семестре |

Оценка за экзамен 1 или 2 означает, что экзамен не сдан: в этом случае итоговая оценка равна оценке за экзамен, а работа в семестре будет уже учитываться на пересдаче.
